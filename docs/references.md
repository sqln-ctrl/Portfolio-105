# Reference review

Reviewed on 10 September 2026. The following are design observations and implementation choices, not permission to copy source, branding, artwork, or text.

| Supplied reference | Useful principle observed | Loopcodez interpretation |
| --- | --- | --- |
| [Adam Mount / Kavimada](https://adammount.org/) | Distinctive identity-led presentation, a personal two-person studio story, and direct collaboration | A recognisable loop mark, a concise founder statement, and a direct enquiry path |
| [Creativeans](https://www.creativeans.com/) | Clear business positioning, visible featured work, and explicit service breadth | Short value proposition, approved projects, and six understandable service disclosures |
| [Milan Compain](https://milancompain.com/) | Oversized typography, spatial particles, and a focused creative-developer identity | Expressive display type, restrained particles, and a decorative 3D layer behind real HTML |
| [AMIX Three.js gallery](https://amix-design.com/tl/web-g-threejs/) | Playable WebGL examples with clear interaction expectations and mobile access | Procedural geometry, a plain scroll cue, and a lower mobile render budget |
| [Studio Merge](https://www.studio-merge.com/) | Characterful studio voice, a broad but coherent creative offering, and a clear portfolio/contact flow | Human copy, staggered work panels, and an expressive final invitation |
| [Trionn](https://trionn.com/) | A signature dimensional mark, restrained interface chrome, and interactive deformation | An original infinity object with scroll-based separation, floating crystals, and accessible fallbacks |

Adam Mount and Milan Compain initially failed text extraction but were successfully opened and visually inspected in the browser. Trionn’s hero was also visually inspected. The other three sites were reviewed through their accessible web content; no pixel-perfect visual claims are made for those pages.

The selected direction intentionally omits a decorative wire grid. No reference-site media, logos, code, or client work were imported.
