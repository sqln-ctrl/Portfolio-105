Purpose: give Cursor one coherent source of truth so the team can design and build Studio 105 from a blank canvas, not recycle the old portfolio.
What Studio 105 is
Studio 105 is a new digital studio started by Umer and Saqlain, roommates whose studio identity comes from Room 105. The room number is the origin story, not a visual limitation. The site must feel like a capable modern creative-tech studio that can design, build, animate and ship polished digital products.
Non-negotiable reset
Do not import the old portfolio as a base.
Do not reuse its theme, layout, frontend architecture, icons, 3D assets, graphics, component library or visual language.
Do not crawl the founders' old repositories to auto-populate portfolio work.
GitHub profiles are references only; projects are selected deliberately later.
Blender is optional and not a prerequisite. Prefer procedural Three.js, SVG, shaders, 2.5D and licensed/open GLB assets.
